# VALENTINO Jewellery

A multi-page jewellery storefront built with HTML, CSS, and vanilla JavaScript. The project presents jewellery collections through an editorial dark-and-gold visual identity.

## Pages

- **Home** — brand introduction, featured pieces, and collection highlights
- **Collections / Shop** — product browsing and category-based collections
- **About** — brand story
- **Contact** — contact page
- **Bag / Cart** — shopping cart experience
- **Checkout** — checkout page

## Storefront Features

- Product catalogue rendered from JavaScript product data
- Jewellery categories including necklaces, rings, bracelets, and sets
- Search interface
- Wishlist and cart controls with item counters
- Responsive navigation, including a mobile menu
- Custom dark styling with gold accents
- Web app manifest and launcher icons

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Cormorant Garamond and Montserrat
- Web App Manifest

## Run Locally

This is a static frontend project. You can open `index.html` in a browser or run it with a local development server.

```bash
git clone https://github.com/aya-aboelkheir/VALENTINO-Jewellery.git
cd VALENTINO-Jewellery
```

Then open `index.html` or start a local server from the project folder.
